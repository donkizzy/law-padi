# Lettering provenance

The standalone symbols are original path drawings. They use no fonts.

A and B use Public Sans SemiBold as the starting point for the accompanying name. C uses Source Serif 4 Semibold. The lettering has custom spacing and a square domain period, and all letters have been converted into SVG paths. No fonts are needed to display these logo SVGs.

Sources retrieved 12 October 2026:

- [Public Sans project](https://github.com/uswds/public-sans), `fonts/ttf/PublicSans-SemiBold.ttf`; [license](https://github.com/uswds/public-sans/blob/master/LICENSE.md). The project directs users to apply SIL OFL 1.1 to the combined font.
- [Source Serif project](https://github.com/adobe-fonts/source-serif), `release/TTF/SourceSerif4-Semibold.ttf`; [license](https://github.com/adobe-fonts/source-serif/blob/release/LICENSE.md), SIL OFL 1.1.

Copies of both license documents are retained alongside this note. No modified font software is being distributed; these are outlined logo artworks. Presentation labels use system typography and are not part of the marks.

The temporary font downloads and fontTools installation used by `build_concepts.py` are under `/private/tmp/constitution-logo-fonts` and `/private/tmp/constitution-logo-python`. No application dependencies or lockfiles were changed.
