# constitution.ng — Open Clause logo kit

Direction A was selected on 12 October 2026. This kit develops that direction into reusable logo artwork. It does not modify or publish the application.

Start with **`identity-overview.png`**. Use **`svg/constitution-ng-horizontal-green.svg`** as the primary logo.

- `svg/`: horizontal, stacked, wordmark-only, symbol and small symbol, each in green, black and white. White symbol geometry is optically adjusted.
- `png/`: transparent raster exports; 2,400 px wide for horizontal/wordmark, 1,024 px for the regular symbol/stacked layout, and 64 px for the small symbol.
- `web/`: SVG/ICO favicons, 16/24/32/48/64 px favicon PNGs, 180 px Apple touch icon, 192/512 px icons, 512 px maskable icon, rounded app preview and setup snippets.
- `guidelines/`: one-page visual guide, editable usage guide, palette data and validation record.
- `presentation/`: a standalone HTML presentation and one PNG per slide, including six relevant application studies.
- `licenses/`: Public Sans license and lettering provenance.

All logo SVG lettering is outlined. You do not need an installed font to use the logos. The masters have real transparent openings and use filled vector geometry without filters, masks, images or live text.

The green-and-white pair is `#008751` / `#FFFFFF`. Read the guide before resizing or preparing print artwork. SVGs are scalable RGB masters, not CMYK press-ready proofs.

The web assets are ready to copy; they have not been installed into the frontend. The presentation is illustrative and does not claim that the example guide, social account or source-sharing screen exists.
